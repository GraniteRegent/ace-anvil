## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **ACE Config Builder** | Visual interface for configuring all ACE3 medical and interaction settings |
| **Pack Exporter** | Export your ACE settings as a mission-ready config file |
| **Preset Library** | Save named ACE configurations for different mission types |
| **Compatibility Check** | Flag known conflicts between ACE and other loaded mods |
